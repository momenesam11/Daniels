# 🎨 Daniels - Portfolio Website

A modern and responsive personal portfolio website built using **HTML, CSS, and JavaScript**, designed to showcase skills, projects, and personal branding in a clean and professional way.

---

## 🚀 Live Deom : https://momenesam11.github.io/Daniels/

---

## 🚀 Overview

Daniels is a fully responsive portfolio template that highlights:

* Personal introduction
* Skills & services
* Portfolio projects
* Testimonials
* Contact section

The project focuses on delivering a smooth user experience with modern UI design.

---

## ✨ Features

* 📱 Fully Responsive Design
* 🎯 Clean and modern UI
* 🧩 Organized sections (About, Services, Portfolio, Contact)
* ✨ Smooth scrolling and animations
* 🖼️ Portfolio showcase section
* 📩 Contact form UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript
* Font Awesome
